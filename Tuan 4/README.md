# Dự Án Kiểm Thử Tự Động - Tuần 04 (Nhóm Web)

Dự án kiểm thử tự động (Automation Testing) giao diện trang web `the-internet.herokuapp.com` sử dụng ngôn ngữ Python, thư viện Selenium WebDriver và framework pytest.

## 1. Yêu cầu môi trường
* **Python**: Phiên bản 3.8 trở lên.
* **Trình duyệt**: Google Chrome (phiên bản mới nhất).

## 2. Hướng dẫn cài đặt
Mở Terminal (hoặc Command Prompt) tại thư mục dự án và chạy câu lệnh sau để cài đặt các thư viện cần thiết:

```bash
pip install selenium pytest
